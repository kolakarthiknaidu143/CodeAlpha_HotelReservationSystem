# Hotel Reservation System

A console-based Hotel Reservation System developed using Java for the CodeAlpha Java Programming Internship.

## Features
- View Available Rooms
- Book Hotel Room
- View Booking Details
- Cancel Booking
- Payment Simulation
- File Handling using booking.txt

## Technologies Used
- Java
- OOP Concepts
- File Handling
- Console Application

## Project Structure
- Main.java
- Room.java
- Reservation.java
- HotelService.java
- booking.txt
